VOXELCRAFT
A single-player voxel survival game modelled on Minecraft Java 1.21.11.
Private, non-commercial. Runs in your browser, no internet needed once it is open.


HOW TO PLAY

  Mac      double-click  "Play Voxelcraft.command"
  Windows  double-click  play.bat
  Linux    run           ./play.sh

A small window opens with a web address in it, and the game opens in your browser.
Leave that window alone while you play; closing it stops the game.

It needs Node (nodejs.org) or Python 3 on the machine — one of them is almost
certainly already there. Nothing gets installed.

The first time on a Mac, macOS may say it cannot check the file for malware:
right-click the file, choose Open, then Open again.


CONTROLS

  Mouse            look (click the game once to capture the mouse)
  W A S D          move
  Space            jump; double-tap in Creative to fly
  Shift            sneak (you will not walk off an edge)
  Ctrl             sprint
  Left mouse       mine (hold), attack
  Right mouse      place, use, eat (hold), open doors and chests
  1-9 / wheel      pick a hotbar slot
  Q                drop the item (Ctrl+Q for the whole stack)
  F                swap with your off hand
  E                inventory; right-click a table, furnace or chest to open it
  T                chat; / opens a command
  F3               debug overlay
  F5               third person
  Esc              pause


WHERE TO START

  Punch a tree, make planks, make a crafting table, make a pickaxe.
  Mine stone, then coal, then iron. Sleep in a bed to skip the night.
  Everything is where it is in Minecraft: the recipes, the loot, the mobs,
  the structures, the Nether and the End, and the dragon at the end of it.

  Worlds save to your browser, on this machine. Same browser, same worlds.


SOUND

  Turn it up. Every effect is Minecraft's own recording, picked and pitched
  the way the game picks and pitches it. Click the window once before you
  expect to hear anything - browsers keep sound off until you do.

  The music and the records are not in the download — they are about three
  hundred megabytes on their own, more than ten times everything else here.
  To add them, run the fetcher once and then start the game again:

    Mac      double-click  "Get the music.command"
    Windows  double-click  get-music.bat
    Linux    run           ./get-music.sh

  That one needs Node; it takes a couple of minutes and only has to be done
  once. Stopping it partway is fine, it picks up where it left off.


ABOUT THE FILES

  game/        the game itself
  server.mjs   the small server the launchers use

The textures, models and sounds are Mojang's, fetched from their own files. They are
here so this copy is playable; they are not redistributed anywhere else.
